# Manga AI Translator - Backend

هذا المجلد مخصص للمحرك الخلفي للمنصة.

## المهام الرئيسية
- البحث عن المانغا والمانهوا.
- جلب بيانات الأعمال والفصول من المصادر المسموح بها.
- تخزين بيانات الأعمال والفصول.
- متابعة الفصول الجديدة تلقائياً.
- ترجمة الفصول إلى العربية بالذكاء الاصطناعي.
- حفظ كل فصل بعد اكتمال ترجمته.
- استئناف الترجمة عند انقطاعها.

## التقنية
- Python
- FastAPI
- PostgreSQL
- Redis
